# Multilanguages Dictionary

> 万能多语言词典 —— 使用中文即可搜索多种语言词汇

---

## 项目简介

本项目是一个多语言词典 Web 应用，支持中文搜索任意目标语言。  
特点包括：

- 中文为核心搜索语言，可查多达 100 多种语言
- 支持语言选择与切换
- 可将 JSON 数据转换为数据库文件（`.db`）
- 响应式网页设计，可直接在浏览器使用

---

## 使用说明

### 1️⃣ 本地启动网页

1. 打开 `index.html` 文件即可在浏览器中使用。
2. 点击顶部语言栏选择目标语言。
3. 输入中文或目标语言单词进行搜索。
4. 搜索结果会以卡片形式显示，分块显示词性、词根和其他信息。
